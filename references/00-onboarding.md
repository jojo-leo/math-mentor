# 00 · Onboarding：建立学习者档案

档案决定后面四层的一切：讲多深、用什么软件写代码、例子从哪来、PBL 用哪个数据集。

## 1. 原则

- **分批问，每批 3–4 题**，不要一次甩出整张问卷。有 AskUserQuestion 工具时，选择题用它；开放题直接对话问。
- **允许跳过。** 用户不想答的字段留空，之后用到时再问。
- **数学水平用"能做什么"来问，不要问"你觉得自己水平如何"。** 自评不可靠，具体任务可靠。
- 问完后把档案念一遍给用户确认，再写入 `~/.claude/math-mentor/profile.yaml`（格式见 `templates/profile.template.yaml`）。

## 2. 四批问题

### 第 1 批：研究身份

1. 你的学科和当前身份？（如：社会学硕士在读、准备申博）
2. 你的研究兴趣，越具体越好。（如："政治消费主义"、"青年就业与数字劳动"、"代际流动"）
3. 你接下来想进入的方向？（如：BCI、计算社科、HCI）——这决定 bridge 时优先拆哪类论文。

### 第 2 批：方法与工具

4. 你常用的研究方法？（多选：OLS/Logit、多层模型、面板固定效应、DID/RDD/IV、倾向得分匹配、事件史/生存分析、SEM、社会网络分析、文本分析、机器学习、定性访谈、民族志……）
5. 你最熟的软件，按熟练度排序？（Stata / R / Python / SPSS / MATLAB）
6. 你常用或能拿到的数据？（CGSS、CFPS、CHARLS、CSS、CLDS、CHNS、CLHLS、GSS、ANES、ESS、WVS、ISSP、PSID、自己采集的数据……）

### 第 3 批：数学基础（用任务探测）

对每一项让用户选 0–3：0 = 没学过；1 = 学过但忘了；2 = 能看懂别人的推导；3 = 能自己推导/计算。

7. 微积分：会求偏导数、做换元积分吗？
8. 线性代数：会手算 2×2 矩阵的特征值吗？知道"正定矩阵"是什么意思吗？
9. 概率论：能写出条件概率和贝叶斯公式，知道概率密度和累积分布函数的关系吗？
10. 数理统计：能推导一个简单模型（如正态均值）的最大似然估计吗？
11. 更高阶：学过实分析 / 随机过程 / 最优化 / 微分方程中的哪些？

可选：如果用户对某项选了 2 或 3，出一道 1 分钟小题验证，把结果记进 `verified` 字段。

### 第 4 批：学习方式与约束

12. 你更喜欢哪种入口？（先讲直觉和图 / 先看代码跑起来 / 先看公式推导 / 先看具体研究例子）
13. 每周能投入多少小时？有没有截止日期（如申请季、某篇论文要用）？
14. 你希望学习笔记保存到哪？（如 Obsidian 库的某个文件夹；不需要就留空）

## 3. 写档案之后

- 告诉用户档案存在哪、怎么改（"说'更新我的档案'即可"）。
- 根据档案给一句话判断：最大的数学缺口在哪，建议第一个学习目标是什么。
- 问用户：现在是贴一段看不懂的论文（bridge），还是直接指定一个概念开始学（learn）？

## 4. 档案更新

以下情况主动提议更新档案：
- 用户提到新的研究兴趣或新数据集；
- 某个数学领域的检查题连续答对（上调该项基础分）；
- 用户换了常用软件。
