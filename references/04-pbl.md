# 04 · Problem-Based Learning：情境化项目设计

当用户对某概念达到 L3+（能推导/实现），设计一个**必须用到这个概念**的研究项目或实际任务。

**关键**：项目必须结合用户的 `research_interests`、`datasets`、`methods`，让 TA 觉得"这就是我想做的事"。

---

## 1. PBL 的三个层次

| 层次 | 适用情况 | 例子 |
|---|---|---|
| **Mini-project** | 概念刚到 L3，1-2 周 | "用 Cox 模型分析 CGSS 里的失业再就业时长" |
| **Research question** | 概念到 L4，可以发会议/工作论文 | "政治消费主义对品牌忠诚的生存分析：CGSS 2015-2021" |
| **Tool-building** | 概念到 L5，做方法贡献 | "实现黎曼度量下的 robust 协方差估计，应用于跨被试 BCI" |

大部分用户适合 Mini-project。

---

## 2. 设计流程

### 2.1 读档案，确定三要素

1. **兴趣领域**：从 `research_interests` 选一个
2. **可用数据**：从 `datasets` 选一个，检查它是否支持该方法（见 `datasets/social-science-datasets.md`）
3. **目标方法**：就是用户刚学的概念

### 2.2 检查可行性（数据结构 vs 方法要求）

**硬约束表**（参考 `datasets/social-science-datasets.md` 的详细版）：

| 方法 | 需要的数据结构 | 不适用的数据 |
|---|---|---|
| Cox 比例风险 | 时间到事件 + 审查（censoring） | 纯横截面 |
| DID | 处理组/对照组 + 前后测量 | 单时点横截面 |
| 多层模型 | 嵌套结构（学生-学校，个体-省份） | 完全独立观测 |
| 面板固定效应 | 同一个体多期观测 | 横截面 |
| RDD | 连续打分变量 + 截断点 | 无连续 running variable |

如果用户的数据不适合刚学的方法：
- 提议换一个数据集（如 CLHLS 适合生存分析，CGSS 不太适合）
- 或提议"创造"合适的变量（如回顾性问题可以构造生存时间）

### 2.3 生成项目框架

用模板（`templates/pbl-project.md`）生成，包括：

1. **研究问题**（1-2 句话）
2. **理论动机**（为什么这个问题有意思？社科理论预测什么？）
3. **数据与变量**（见 codebook 哪章；如果不确定变量名，写"需核对 codebook"）
4. **方法步骤**（用刚学的概念；写成 3-5 步，每步一个检查点）
5. **预期输出**（一张表或一张图）
6. **扩展方向**（如果想投稿/深化，可以怎么改进）

## 3. 示例：Cox 模型 + 政治消费主义

**假设用户档案**：
- `research_interests`: ["政治消费主义"]
- `datasets`: ["CGSS"]
- 刚学完 Cox proportional hazards 模型，达到 L3（能手推 partial likelihood）

**问题**：CGSS 是横截面，不直接有生存数据。但问卷有回顾性问题，如"你从什么时候开始关注环保产品"。可以构造"首次环保消费的时长"。

**生成的项目**：

```markdown
# PBL Project: 政治消费行为的社会扩散：事件史分析

## 1. 研究问题
政治消费行为（如抵制不道德品牌、购买环保产品）在不同社会群体中的"采纳时长"有何差异？社交网络和媒体暴露如何影响采纳速度？

## 2. 理论动机
- **社会学**：Rogers 的创新扩散理论预测早期采纳者（innovators）vs. 晚期大众（late majority）的特征差异
- **政治学**：政治关注、教育与政治参与正相关
- **本项目贡献**：用生存分析量化"扩散速度"，而非静态的"是否参与"

## 3. 数据与变量

**数据集**：CGSS 2015（最新有回顾性问题的年份，需核对）

**因变量**：
- Time-to-event：受访者自我报告"首次因政治/道德原因抵制或选择某品牌"的年龄
- Censoring：未发生过此行为的受访者在访谈时年龄

**自变量**（需在 codebook 核对具体题号）：
- 教育水平、政治面貌、社交媒体使用频率、父母政治参与
- 控制变量：性别、城乡、收入

## 4. 分析步骤

### Step 1：数据清洗（检查点：生存曲线图）
- 构造 time = 首次行为年龄 - 出生年
- 构造 event = 1（发生）或 0（censored）
- 用 Kaplan-Meier 画生存曲线：不同教育组的"采纳率"

**检查点**：能画出类似这样的图：
```
1.0 |         [高教育组]
    |               ---___
0.5 |  [低教育组]        ---___
    |      ----_______
0.0 |________________________
    0   10   20   30   40  年龄
```

### Step 2：Cox 模型估计（检查点：系数表）
```stata
stset time, failure(event)
stcox education polface socialmedia parent_activism, robust
```

预期：教育、社交媒体正系数（加速采纳）

**检查点**：能解释 hazard ratio（如 HR=1.5 表示"风险增加 50%"，这里是"采纳速度快 50%"）

### Step 3：检验比例风险假设（检查点：Schoenfeld 残差图）
```stata
estat phtest, detail
stphplot, by(education)
```

如果假设不成立（某变量的效应随时间变化），讨论原因（如早期 vs 晚期扩散机制不同）

### Step 4：分层分析（检查点：交互项表）
- 社交媒体的效应在城乡是否不同？
- 教育的效应在不同政治面貌下是否异质？

### Step 5：稳健性检查（检查点：结论稳定吗）
- 换不同的 censoring 定义（如"听说过但未做"算不算 censored？）
- 排除极端年龄组

## 5. 预期输出

**表 1**：描述统计（按 event 发生与否分组）  
**表 2**：Cox 模型结果（3-4 个 model，逐步加变量）  
**图 1**：K-M 生存曲线（按教育分组）  
**图 2**：Schoenfeld 残差（诊断比例风险）

## 6. 如果想投稿

**会议**：社会学年会 ASA、中国社会学会  
**期刊**：《社会学研究》、《社会》

**需要强化**：
- 更严格的理论假设（如 Bourdieu 的文化资本 vs. 政治消费）
- 工具变量（如果担心内生性：教育 → 政治消费可能反向因果）
- 跨年份对比（如果有 CGSS 多年数据，做队列分析）

## 7. 里程碑时间表

- Week 1-2：数据清洗 + K-M 曲线（达到 Step 1）
- Week 3：跑通 Cox 模型（达到 Step 2）
- Week 4：诊断和稳健性检查（达到 Step 3-5）

**完成标志**：能向外行解释"为什么高教育者更快采纳政治消费，这个结论在统计上站得住"。

---

**下一步**：
1. 现在开始 Step 1（我帮你写数据清洗代码）
2. 调整项目方向（如换个数据集或研究问题）
3. 先做一个更简单的 mini-project
```

## 4. 其他领域示例（简略版）

### BCI + Riemannian 几何
**项目**：跨被试 EEG 解码器迁移学习  
**数据**：BNCI Horizon 2020 公开数据集（运动想象）  
**任务**：用 `pyRiemann` 的 `TangentSpace + LogisticRegression`，实现零校准（zero-calibration）分类  
**检查点**：在新被试上的准确率比欧氏 baseline 高 10%+

### 计算社科 + 因果森林（Causal Forest）
**项目**：社交媒体使用对政治极化的异质性效应  
**数据**：自建 survey + social media trace  
**任务**：用 GRF (Generalized Random Forest) 估计不同人口学群体的 treatment effect  
**检查点**：画出 CATE（条件平均处理效应）的分布图

---

## 5. PBL 后的跟进

项目完成后（通常 4-8 周），问用户：

1. 想把它投出去吗？（帮 TA 润色成会议摘要或工作论文）
2. 想深入哪个部分？（如"比例风险假设不成立，想学时变系数模型"）
3. 想学下一个方法吗？（根据项目中暴露的新需求，推荐下一个概念）
