# Math Mentor：社科研究者的前沿数学学习系统

帮助社会科学研究者学习前沿研究（BCI、计算社科、HCI、神经工程等）中的数学/统计方法。

## 核心理念

**从看不懂的东西倒推 → 只学必需的 → 学完马上在自己的研究里用一次。**

不是"先学完一本教材再用"，而是"用什么学什么，学完就用"。

---

## 四层学习系统

### Layer 1: Paper-to-Math Bridge（论文→数学桥梁）
贴一段看不懂的论文，AI 识别用到哪些概念、画依赖树、给 6-8 周学习路径。

### Layer 2: Tutor（苏格拉底式导师）
不灌输，引导你自己发现。按你的数学基础分慢 / 中 / 快三档推导速度：基础薄弱时每一步拆开讲、先说为什么、每步一个小检查、用数字验证。抽象概念配 2–3 个不同视角的现实案例。

### Layer 3: Study Group（模拟学习小组，可选）
只在你主动要求时启动：5 个虚拟同学（数学系/工程系/物理系/统计系/社科）从不同角度讨论同一个概念，你可以随时插话。

### Layer 4: Problem-Based Learning（情境化项目）
结合你的研究兴趣、常用方法和数据集（CGSS/CFPS/GSS 等），设计一个必须用到刚学概念的研究项目。

## 使用方式

### 首次使用（建档）

```bash
# 说"math-mentor"或"教我 X"会自动触发建档
你：教我 Cox 模型

AI：在开始前，让我先了解一下你的背景...
    [4 批问卷，每批 3-4 题]
```

档案保存在 `~/.claude/math-mentor/profile.yaml`，之后所有讲解都按这个档案校准。

### 模式 1：从论文开始（推荐）

```bash
你：我看这篇 BCI 论文看不懂
    [贴论文段落或 PDF]
    "We compute the Fréchet mean on the SPD manifold..."

AI：📊 检测到 5 个核心概念...
    🎯 最小学习路径（6 周）...
    Week 1-2: SPD 矩阵与流形直觉
    Week 3-4: 黎曼度量与测地线
    Week 5-6: 用 pyRiemann 复现论文

    现在想：
    1. 从 Week 1 开始学
    2. 先看学习小组讨论
    3. 调整路径
```

### 模式 2：直接学概念

```bash
你：教我生存分析

AI：好的。在开始前，你听说过 censoring（审查）吗？
    A) 没听过
    B) 听过但说不清
    C) 能举例
    [根据你的回答调整起点，苏格拉底式提问]
```

### 模式 3：学习小组讨论

```bash
你：让学习小组讨论一下"为什么 Cox 模型不需要指定 baseline hazard"

AI：[Bob]: 我觉得是因为 partial likelihood 把 h_0(t) 消掉了...
    [Alice]: Bob 你说的对，但不够严格。数学上...
    [Carol]: 我从物理角度理解...
    [你]: 等等，Alice 你说的"条件概率"是指...
```

### 模式 4：做项目

```bash
你：我已经学完 Cox 模型了，给我设计一个项目

AI：[读你的档案：研究兴趣 = 政治消费主义，数据 = CGSS]
    
    📋 PBL Project: 政治消费行为的社会扩散：事件史分析
    
    研究问题：政治消费行为在不同社会群体中的"采纳时长"有何差异？
    数据：CGSS 2015（需核对回顾性问题）
    方法：Cox 比例风险模型
    
    分析步骤：
    Step 1: 数据清洗 + K-M 曲线
    Step 2: Cox 模型估计
    Step 3: 检验比例风险假设
    ...
    
    现在开始 Step 1？
```

## 特色功能

### ✅ 校准到你的水平
根据档案自动调整：
- 社科背景 → 多讲实证例子、少讲抽象证明
- 工科背景 → 先给代码、再讲原理
- 数学系 → 严格证明优先

### ✅ 不编造
- 讲论文前先确认读到了正文（PDF 只提取到标题/乱码时会如实告诉你，并改用 `pdftotext` 或请你提供文本）。
- 区分"原文写的"和"补充的通用知识"；重建的公式会标注。
- 数值例子只在实际运行代码或逐步手算后给出。

### ✅ 完整的学习记录
如果设置了笔记目录，每次会话都会写一份详细记录：还原问答过程和每一步推导，方便日后复习。

### ✅ 结合你的研究
PBL 项目用你的兴趣领域和常用数据集，不是泛泛的"教科书习题"。

### ✅ 进度持久化
每次学到哪、困惑点、检查题结果都记录，下次继续。

### ✅ 多模态入口
公式、代码、图、类比四种方式，看你喜欢哪个。

## 技术细节

- **计算工具**：优先用 Python，找不到就用 MATLAB，都不可用时逐步手算并反向验算。
- **读 PDF**：建议安装 poppler（`pdftotext`）。文件路径含中文时，先复制到英文路径再提取。
- **Obsidian 集成**：如果你用 Obsidian 做笔记，档案里设置 `notes_dir`，学习路径和项目会自动复制一份到那里。
- **隐私**：你的档案和进度只存本地，不随 skill 分享。
